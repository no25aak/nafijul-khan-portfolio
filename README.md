# Nafijul Khan Ornob profile site

A five-page student profile site built with plain HTML, CSS, and JavaScript.

## Pages

- `index.html` — About Me
- `interests.html` — Technical Interests
- `portfolio.html` — Portfolio
- `project-details.html` — Project Details
- `contact.html` — Contact Me

## Run locally

Open `index.html` in a browser. The site has no build step and uses no JavaScript libraries.

The contact form is a client-side demonstration. It validates the fields and shows a message preview in the browser. It does not send or store submitted details. Add your own email and GitHub links before publishing.

## Assignment evaluation

Carry out the heuristic evaluation yourself using the provided template. Do not involve other people. Use the WAVE browser extension for the required accessibility conformance test and complete the supplied report template. The reports are separate submission files and are not part of the site ZIP.

## Personalise before submission

Replace the project placeholders with work you completed and can explain. Update your contact details and add a suitable personal image or keep the provided placeholder.
